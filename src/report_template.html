RQ3 — Transformers are the most recipe-robust family and the least seed-stable

BERT swings least when the training recipe changes (0.670 spread against 0.819 for CNN and 0.908 for traditional ML) and most when only the random seed changes (SD 0.385, against 0.095 for CNN and exactly 0 for LR/SVM). No family wins both axes, so "consistent" has to be qualified before it can be answered.

Two axes, both spreads — smaller is better. Robustness ↓ = F1 spread across the six training recipes. Stability ↓ = F1 spread across three random seeds.

Length control — can a word-counter beat the models?

How much of each test set is solvable from document length alone
A "classifier" that sees nothing but the word count. 0.5 means length tells you nothing. Anything near 1.0 means a high score on that test set is not by itself evidence of anything.

LIAR is almost entirely solvable by counting words. — its fake statements have a median of 16 words against 367 for the real articles. The WELFake sets sit near , so length is genuinely uninformative there.

Same recipe, length confound removed
Real + Synthetic against a twin built from synthetic fakes written at ~25, ~100 and ~400 words, with each real article cut to match its pair. Everything else — the pairing, the class balance, the manipulation types — is identical, so length is the only variable.
View raw data — both recipes on every test set

The length-controlled recipe is the better detector where it counts. On cleaned WELFake — the set where word-counting doesn't help — removing the confound raises AUC for three of the four models ( on average). On LIAR it changes scores in both directions: LR falls 0.943 → 0.690 and CNN rises 0.054 → 0.552. Both moves have the same cause. LR was riding the length gap and CNN was riding it backwards; neither was reading the facts.
